# Fonti Ufficiali

Usare questa lista quando la richiesta tocca regole normative, dati annuali, tracciati, controlli ufficiali o adempimenti. Verificare sempre online se la regola puo essere cambiata di recente.

## Politica Fonti

- Preferire fonti ufficiali: Agenzia Entrate, INPS, INAIL, MEF/Finanze, Garante Privacy, CNEL, Normattiva, Gazzetta Ufficiale.
- Non usare blog, forum o codice GitHub come fonte normativa primaria.
- Riportare link e data di consultazione.
- Se una fonte ufficiale non e trovata, dire `fonte ufficiale non trovata` e non approvare la parte normativa.
- Per software di controllo, distinguere sempre tra "controllo interno" e "controllo ufficiale ente".

## Fonti Per Area

- **Paghe/INPS**: circolari INPS, messaggi INPS, software/validatore UniEmens, specifiche UniEmens.
- **INAIL**: istruzioni autoliquidazione, basi di calcolo, tassi, servizi online INAIL.
- **Agenzia Entrate**: specifiche tecniche, provvedimenti, software di controllo, Desktop Telematico.
- **Fattura/SdI**: specifiche FatturaPA, controlli SdI, ricevute/notifiche.
- **GDPR**: Garante Privacy, testo GDPR, EDPB quando serve.
- **CCNL**: CNEL e testi contrattuali ufficiali o depositati.
